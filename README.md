## 📌 Project Overview

This repository features a modern, responsive, and visual landing page built to showcase various **Monster Energy** product lines (including classic flavors, Rehab, and Juiced variants). 

The goal of this project was to practice front-end layout techniques, custom UI design, CSS styling, and deployment workflows via **GitHub Pages**.

---

## 🛠️ Built With

- **HTML5**: Semantic structure and content organization.
- **CSS3**: Custom layouts, typography, hover effects, and responsive design.
- **VS Code**: Code editing and local testing.
- **GitHub Pages**: Web hosting and live deployment.
